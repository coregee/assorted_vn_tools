# Assorted VN Tools

Assortment of extract/repack tools for miscellaneous visual novels.

- `dasaku_tools`, `etutane_tools`, and `sstar_tools` extract and repack their
  respective game formats.
- [`llm_translation_tools`](llm_translation_tools/README.md) is a local browser
  editor for translating the extracted JSON with a model served by an OpenAI-compatible endpoint (such as Lemonade).
